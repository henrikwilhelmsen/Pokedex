# Pokedex

Go Pokedex CLI app, built as a part of the [boot.dev](boot.dev) backend developer course.

## Usage

Clone the project and run the CLI REPL with ´go run´:

```shell
go run .
```

Use the help command to list available commands, or exit to exit the app:

```shell
Pokedex > help
```

```shell
Pokedex > exit
```
